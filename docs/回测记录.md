## 2026-09-18 — 市场基线（P2 验收，T10）

**数据范围**：football-data CSV；4 个赛季（2021/22 – 2024/25）× 9 联赛；
入库后总数 11,884 条，部分场次缺少 avg/max/b365 之一。
**回测段**：2024-08-01 起的全部 ≥2024/25 赛季比赛。
**命令**：
```bash
python -m football_lottery.backtest.baseline --start 2024-08-01 --odds {avg|max|b365}
```

### 三种赔率口径对比（设计文档 §4.1 口径试验）

| 赔率口径 | 场次 | logloss | Brier | 准确率 |
|---|---|---|---|---|
| **avg（均价）** | 3,524 | **0.9744** | **0.5808** | **0.5261** |
| max（最高价） | 4,145 | 0.9855 | 0.5887 | 0.5131 |
| b365（Bet365 单家） | 4,762 | 0.9824 | 0.5858 | 0.5200 |

**结论**：avg 三项全部最优，按计划已写入 `config.yaml` 的 `market.odds_source: avg`（默认值）。
所有后续模型的对照锚点 = 0.9744 / 0.5808 / 0.5261。

**现实意义**：融合模型 logloss 必须 ≤ 0.9744 才算增量（否则按 §1.5 启用 market_primary 降级）。

## 2026-09-18 — Dixon-Coles 单路（T13 半衰期敏感性表）

**数据范围**：5 赛季 × 9 联赛 = 15,868 场全部带比分；回测段 = 2024-08-01 起 ≥ 2024/25 赛季比赛（每联赛约 612–1104 场）。
**命令**（后两个走 half-life 敏感性扫描）：
```bash
python -m football_lottery.backtest.dc --start 2024-08-01 --half-life {90|180|365} --refit-days 30 --max-train 1500
```

| half_life (days) | 场次 | logloss | Brier | accuracy |
|---|---|---|---|---|
| 90 | 6,288 | 1.0117 | 0.6043 | 0.5094 |
| 180 | 6,288 | 0.9991 | 0.5964 | 0.5143 |
| **365** | **6,288** | **0.9963** | **0.5944** | 0.5119 |

**结论**：365 天半衰期略胜（logloss/Brier/acc 三项接近，acc 180 微胜）。按设计文档 "不许只记最优点" 记录三点全量。
较优值 365 已写入 `config.yaml dc.half_life_days`。

**相对市场基线的差距**（所有 DC 半衰期都弱于市场）：

| 路 | logloss | 与市场差距 |
|---|---|---|
| avg（市场基线） | **0.9744** | — |
| DC (hl=180)       | 0.9991  | +0.0247 |
| DC (hl=365)       | 0.9963  | +0.0219 |

DC 单路略弱于市场，符合设计文档 §4.2 预期；其价值在于为融合层提供独立增量信号。
**若融合层 logloss 减不到 ≤ 0.9744，按 §1.5 启用 market_primary 降级**（后续 T19 验收判定）。
