## 2026-09-18 — 市场基线（P2 验收，T10）

**数据范围**：football-data CSV；4 个赛季（2021/22 – 2024/25）× 9 联赛；
入库后总数 11,884 条，部分场次缺少 avg/max/b365 之一。
**回测段**：2024-08-01 起的全部 ≥2024/25 赛季比赛。
**命令**：
```bash
python -m football_lottery.backtest.baseline --start 2024-08-01 --odds {avg|max|b365}
```

### 三种赔率口径对比（设计文档 §4.1 口径试验）

| 赔率口径 | 场次 | logloss | Brier | 准确率 |
|---|---|---|---|---|
| **avg（均价）** | 3,524 | **0.9744** | **0.5808** | **0.5261** |
| max（最高价） | 4,145 | 0.9855 | 0.5887 | 0.5131 |
| b365（Bet365 单家） | 4,762 | 0.9824 | 0.5858 | 0.5200 |

**结论**：avg 三项全部最优，按计划已写入 `config.yaml` 的 `market.odds_source: avg`（默认值）。
所有后续模型的对照锚点 = 0.9744 / 0.5808 / 0.5261。

**现实意义**：融合模型 logloss 必须 ≤ 0.9744 才算增量（否则按 §1.5 启用 market_primary 降级）。
